 ## Descripción del Proyecto

El proyecto consiste en el desarrollo de un sitio web educativo utilizando HTML5 y CSS3.

El objetivo es crear una plataforma simple que permita visualizar información de usuarios, proyectos y perfiles, aplicando buenas prácticas de diseño web y estructura semántica.

🧱 Construcción de las páginas HTML

Las páginas fueron desarrolladas utilizando etiquetas semánticas de HTML5 como:

<header>: encabezado principal
<nav>: menú de navegación
<main>: contenido principal
<section>: organización del contenido
<footer>: pie de página

Se implementaron múltiples páginas:

index.html → página principal
proyectos.html → listado de proyectos
perfil.html → visualización de perfiles de usuarios
🎨 Estilos CSS utilizados

Para el diseño se utilizó CSS3, aplicando:

Flexbox y Grid → para organizar los perfiles en filas y columnas
Box Model → padding, margin y border
Sombras (box-shadow) → para efecto de tarjetas
Border-radius → para bordes redondeados
Hover effects → animaciones al pasar el mouse
Diseño responsive → adaptación a distintos tamaños de pantalla

Los perfiles fueron diseñados como tarjetas (cards), centradas y con estilo moderno.
